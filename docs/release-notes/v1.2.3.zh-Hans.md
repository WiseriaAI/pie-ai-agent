# v1.2.3 — 自定义规则，OpenAI 回归正轨

本次更新新增「自定义规则」设置页，让 Agent 在每个任务中都遵循你的长期偏好；OpenAI provider 迁移到 OpenAI 当前的官方 API，最新的 GPT‑5.x 模型重新支持工具调用；并清理了界面中最后几处不跟随你语言设置的地方。

## 自定义规则

新增 **设置 → 自定义规则** 页面：一个自由文本框，写下你希望 Agent 一直遵守的习惯——语气、偏好的网站、输出格式等等，从此不用在每次对话开头重复交代。Agent 在每个任务开始时读取这些规则，并在安全边界内优先于默认行为执行。

- **写一次，处处生效** —— 规则在任务启动时快照，每个任务都带着你的偏好开始；中途修改从下一个任务起生效。
- **安全边界不动摇** —— 规则不能解锁 Agent 本来做不到的事：网页内容仍然不可信，授权确认仍然走侧栏面板。

## OpenAI provider

- **GPT‑5.x 重新支持工具调用** —— OpenAI 最新模型在旧的 chat completions 端点上拒绝「工具 + 推理」同时开启的请求，导致 Agent 任务直接失败。Provider 现已迁移到 OpenAI 的 Responses API，推理与工具可以共存，gpt‑5.x 模型开箱即用。其它 OpenAI 兼容 provider 不受影响。

## 说你的语言

- **自动生成的会话标题** 现在跟随助手语言设置，不再固定输出中文。
- **终止任务的提示语**（「任务已取消」等）现在按界面语言渲染——之后切换语言，历史会话里的提示也会跟着变。
- **录制步骤行** 改为语言中立存储、显示时组词，已录制的步骤也会跟随语言切换。

## 修复与其它

- **会话标题不再卡住** —— 一个时序竞态曾导致标题生成被静默跳过，会话停留在默认标题上。现在标题生成稳定可靠。
- **大版本更新后展示更新日志** —— minor 或 major 版本更新后，Pie 会打开一次官网更新日志页面；patch 更新保持静默。
